🎯 Feature Flag: config-welcome-message

This page demonstrates the ld_variation() Jinja2 template helper:

{% raw %}{{ ld_variation('config-welcome-message', 'hello there!') }}{% endraw %}

Result:

{{ ld_variation('config-welcome-message', 'hello there!') }}

🔍 How It Works

The template helper evaluates the LaunchDarkly flag config-welcome-message and returns:

  • Flag value if the flag exists and is configured
  • Default value ('hello there!') if the flag doesn't exist or evaluation fails

🛠️ Try It Yourself

To see different values:

  1. Create the flag config-welcome-message in your LaunchDarkly dashboard
  2. Set different string values (e.g., "Welcome to our app!", "Hello world!", etc.)

  4. Try targeting different users or segments
